## 题解

### 题意
**形式化题意**

给定一棵包含 **n** 个结点的树，结点编号为 **1** 到 **n**，每条边有一个正整数边权。

对于树上两个结点 **u, v**，定义它们的“残余关联”为树上 **u** 到 **v** 的简单路径上所有边权的**最小值**。

有 **q** 次询问。每次询问给定两个整数 **k'** 和 **u'**，以及一个全局参数 **c ∈ {0, 1}**。设上一次询问的答案为 **lastans**（第一次询问前 **lastans = 0**），则真实的询问参数为：

- **u = u' ⊕ (lastans × c)**
- **k = k' ⊕ (lastans × c)**

其中 **⊕** 表示按位异或。

对于每次询问，求满足以下两个条件的结点 **v** 的数量：

1. **v ≠ u**
2. **u 与 v 的残余关联至少为 k**（即树上 **u** 到 **v** 路径上的最小边权 **≥ k**）

输出每次询问的答案。注意本题**强制在线**：后一次询问的真实参数依赖前一次询问的答案。

**输入说明**

- 第一行：**n q c**
- 接下来 **n-1** 行：每行 **p_i q_i r_i**，表示结点 **p_i** 与 **q_i** 之间有一条边权为 **r_i** 的边
- 接下来 **q** 行：每行 **k' u'**（注意输入顺序为先 **k'** 后 **u'**）

**数据范围**

- **1 ≤ n, q ≤ 10⁵**
- **1 ≤ p_i, q_i, u_i ≤ n**
- **1 ≤ r_i, k_i ≤ 10⁹**
- 对于 35% 的数据：**c = 0**
- 对于其余 65% 的数据：**c = 1**

### 解法

这个题的离线做法我之前讲过[在这里](https://iceking.nsoj.top/blog/Pictionary)

那么这里就不讲离线做法。

我们发现我们在线的瓶颈在于我们需要知道并查集是在什么时机合并的。

那么这个时候就应该想到Kruskal重构树这个东西。

我们还是把边权按照从大到小排序。

然后我们每次合并并查集的时候创造一个新的节点与这两个并查集的代表节点连边。

这个点的权值就是这个点的边权。

最后我们建出来的二叉树每个叶子节点到根的路径上的节点的点权一定是单调不增的。

那么我们就可以通过倍增跳祖先的方式找到深度最小的一个权值$\geq K$的节点

这个节点的子树中叶子节点的数量就是这个点能通过边权$\geq K$的边到达的节点

时间复杂度为$O(n+q \log n)$

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=2e5+10;
const int inf=1e9+10;
int n,q,c;
struct node{
    int x,y,r;
    bool operator<(const node &b)
    {
        return r>b.r;
    }
}e[N];
int fa[N],d[N];
inline int get(int x)
{
    if(x==fa[x]) return x;
    return fa[x]=get(fa[x]);
}
int id[N],idtot;
int head[N],ver[2*N],nxt[2*N],tot;
int f[N][30];
inline void add(int x,int y)
{
    ver[++tot]=y;
    f[y][0]=x;
    nxt[tot]=head[x];
    head[x]=tot;
    return ;
}
int val[N],siz[N];
inline void solvef(int x)
{
    for(int i=1;i<=22;i++)
    {
        f[x][i]=f[f[x][i-1]][i-1];
    }
    if(x<=n) siz[x]=1;
    for(int i=head[x];i;i=nxt[i])
    {
        int y=ver[i];
        solvef(y);
        siz[x]+=siz[y];
    }
}
int ans=0;
inline void getans(int x,int k)
{
    int now=x;
    for(int i=22;i>=0;i--)
    {
        if(val[f[now][i]]>=k) now=f[now][i];
    }
    ans=siz[now]-1;
    cout<<siz[now]-1<<'\n';
}
int main()
{
    // freopen("20.in","r",stdin);
    // freopen("20.out","w",stdout);
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin>>n>>q>>c;
    for(int i=1;i<=n;i++) fa[i]=i,d[i]=1,id[i]=i,val[i]=inf;
    idtot=n;
    for(int i=1;i<n;i++) 
    {
        cin>>e[i].x>>e[i].y>>e[i].r;
    }
    sort(e+1,e+n);
    for(int i=1;i<n;i++)
    {
        int x=e[i].x,y=e[i].y;
        int fx=get(x),fy=get(y);
        if(fx!=fy)
        {
            if(d[fx]>d[fy]) swap(fx,fy);
            if(d[fx]==d[fy]) d[fy]++;
            fa[fx]=fy;
            ++idtot;
            val[idtot]=e[i].r;
            add(idtot,id[fx]);
            add(idtot,id[fy]);
            id[fy]=idtot;
        }
    }
    solvef(idtot);
    for(int i=1;i<=q;i++)
    {
        int k,x;
        cin>>k>>x;
        k^=ans*c;
        x^=ans*c;
        getans(x,k);
    }
    return 0;
}
```
